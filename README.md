# Rheyven Bausas — Portfolio

Static HTML/CSS/JS portfolio ready for Vercel.

## Deploy
1. Push this folder to GitHub.
2. Import the repository into Vercel.
3. No build command is required.
4. The site entry point is `index.html`.

## Local preview
Run `python -m http.server 8107 --bind 127.0.0.1` and open http://127.0.0.1:8107.
No package installation or build step is required.

## Design
The active design uses `assets/css/studio.css`, `assets/css/orange-studio.css`, and `assets/js/studio.js`.
The hero uses a large cutout portrait with an orange tint and gradient fade.
The earlier hanging ID badge styles and script are retained but are not loaded.
The earlier styles and scripts are retained but are not loaded by the page.
See [DESIGN.md](DESIGN.md) for the direction and validation notes.
Project images appear in full color, with enlarged screenshot previews.
The deep-orange hero and contact frame white/black content bands. Light and dark variants
are supported; your theme choice is saved locally.
Typography pairs Space Grotesk headings with DM Sans body text, without decorative italics.
Google Fonts loads both fonts at runtime; system sans-serif is the fallback.
Stack icons use a locally hosted Devicon font (license in `assets/fonts/DEVICON-LICENSE.txt`).
The contact form opens an email draft; it does not send or store messages.
